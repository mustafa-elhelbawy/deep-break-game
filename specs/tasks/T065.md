## Smoke Test Checklist

### Cold Launch + Title Screen (T044–T046)

- [ ] App opens directly to title screen — NOT the game
- [ ] "DEEP" (teal) and "BREAK" (amber) logo visible with Orbitron font
- [ ] Logo floats gently (animation playing)
- [ ] Teal particles drift upward
- [ ] "TAP TO PLAY" pulses
- [ ] Tapping title → game starts, ball sits on paddle
- [ ] After Game Over → Restart → returns to title screen (not directly to game)

### Realistic Ball Movement (T047–T048)

- [ ] Over 20+ bounces: ball does NOT repeat an identical pattern to naked eye
- [ ] Moving paddle quickly LEFT while ball approaches → ball deflects further left
- [ ] Moving paddle quickly RIGHT → ball deflects further right
- [ ] Ball never gets trapped horizontally (MIN_VERTICAL_SPEED still works)

### All SFX Events (T049 + existing)

- [ ] Brick hit (no destroy): no crash, no error sound
- [ ] Brick destroyed: no crash
- [ ] Paddle hit: no crash
- [ ] Ball lost: no crash
- [ ] Game over: no crash
- [ ] Level clear: no crash

### Power-Up W — Wide Paddle (T053)

- [ ] Catch W token (may need to reach level 5+ or test with lowered threshold): paddle visibly widens
- [ ] Paddle reverts to normal after ~10 seconds
- [ ] Catching W again while active: timer resets, stays wide
- [ ] HUD shows "W: WIDE" label and shrinking bar

### Power-Up S — Slow Motion (T054)

- [ ] Catch S token (level 10+): ball noticeably slows
- [ ] Ball reverts to normal speed after ~10 seconds
- [ ] HUD shows "S: SLOW" with shrinking bar

### Power-Up M — Multi-Ball (T055)

- [ ] Catch M token (level 20+): second ball spawns and bounces independently
- [ ] Losing one ball: no life lost, remaining ball continues
- [ ] Losing all balls: one life decremented
- [ ] HUD shows "M: MULTI" (no timer bar)
- [ ] On Game Over/Level Clear: second ball cleaned up

### Collapsing Bricks (T057–T059)

- [ ] At level 10+: some bricks have a red tint and drift downward
- [ ] Ball still bounces off a drifting brick
- [ ] Drifting brick reaches paddle Y: one life lost, dark red flash + shake visible
- [ ] Drifting brick misses paddle (exits bottom): no life lost
- [ ] Below level 10: no drifting bricks

### Flipped Layout (T060–T064)

- [ ] A flipped level eventually appears (~1 in 5 from level 3+)
- [ ] "FLIP LEVEL!" banner displays for ~2 seconds
- [ ] Tapping during banner does NOT launch ball
- [ ] After banner: paddle is at top, bricks are at bottom
- [ ] Ball launches downward on tap
- [ ] Ball exits TOP of screen = life lost
- [ ] Ball bounces off BOTTOM wall
- [ ] Dragging in upper 40% of screen moves paddle
- [ ] Dragging in lower 60% does NOT move paddle
- [ ] Flipped level clears normally → next level is independent roll

### Performance

- [ ] Frame rate feels smooth throughout (no visible stutter)
- [ ] No stutter during 2-ball + mobile bricks + burst particles simultaneously
- [ ] No Godot "!" error icon in corner

### Regression — Phase 1–5 Core

- [ ] Normal levels: ball launches upward, paddle at bottom, bottom = death
- [ ] Score updates correctly
- [ ] Lives show 3 at start
- [ ] Level Clear screen appears when all (destructible) bricks cleared
- [ ] Indestructible bricks (level 10+) never disappear
