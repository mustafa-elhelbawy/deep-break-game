## Part A — AI Agent Prompt

**Task**: Pull main, set the three keystore environment variables, run the Godot headless export command, verify the APK was produced, and install it on a connected Android device.

**Project context**:
- Working directory: wherever you cloned the repo on the Windows build machine (e.g. `C:\dev\deep-break-game`)
- All one-time setup is complete (T041).
- Preset name in `export_presets.cfg` is **"Android Release"** — must match exactly.
- Output APK goes to `build\android\DeepBreak.apk`.

---

### Step 1 — Pull latest main

```powershell
cd C:\dev\deep-break-game   # adjust to your repo path
git checkout main
git pull origin main
```

Verify `export_presets.cfg` has `name="Android Release"` (from T039).

---

### Step 2 — Set environment variables

Open a new PowerShell session and set:

```powershell
$env:DEEP_BREAK_KEYSTORE_PATH = "C:\keys\deep-break.keystore"
$env:DEEP_BREAK_KEY_ALIAS      = "deep-break-key"
$env:DEEP_BREAK_KEY_PASSWORD   = "yourpassword"
```

> These must be set in the same session you run the export. They are not persisted.

---

### Step 3 — Create output directory

```powershell
New-Item -ItemType Directory -Force -Path build\android
```

---

### Step 4 — Run headless export

```powershell
godot.exe --headless --export-release "Android Release" build\android\DeepBreak.apk
```

**Expected output** (approximately):

```
Godot Engine v4.3.stable - https://godotengine.org
OpenGL ES 3.0 Renderer: Disabled
...
Exporting project...
Building Android APK...
Signing APK...
```

**Expected exit code**: `0` (no error).

Check:
```powershell
echo "Exit code: $LASTEXITCODE"   # must be 0
Test-Path build\android\DeepBreak.apk   # must be True
(Get-Item build\android\DeepBreak.apk).Length / 1MB   # typically 20–60 MB
```

---

### Step 5 — Install on device

Connect an Android device via USB with USB Debugging enabled.

```powershell
adb devices   # device must appear as "device" (not "unauthorized")
adb install -r build\android\DeepBreak.apk
```

Expected: `Success`

---

### Step 6 — Quick sanity check on device

1. Open Deep Break from the app drawer
2. Game launches without crash
3. Ball launches on tap, bricks break, score increments

Full smoke test is in T043 — this step is just "does it open?".

---

### Step 7 — Archive the APK

```powershell
Copy-Item build\android\DeepBreak.apk build\android\DeepBreak-v0.5.0.apk
```

Keep the unversioned `DeepBreak.apk` as the "latest" alias. The versioned copy is the release artefact.

---

### Troubleshooting

**"Export template not found"**  
→ Re-run the export template installation from T041 Step 2.

**"Keystore not found" / signing failure**  
→ Verify `$env:DEEP_BREAK_KEYSTORE_PATH` is set correctly in the current session.  
→ Check: `Test-Path $env:DEEP_BREAK_KEYSTORE_PATH` → must be `True`.

**Gradle build fails with SDK error**  
→ Open Godot editor once and confirm SDK path in Editor Settings → Export → Android.

**APK produces but `adb install` fails with "INSTALL_FAILED_UPDATE_INCOMPATIBLE"**  
→ Uninstall the existing version first: `adb uninstall com.deepbreak.game`
