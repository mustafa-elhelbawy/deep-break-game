**Task**: Execute T006 from the Deep Break project — create `scenes/game/Walls.tscn`, a scene containing three infinite-plane collision walls (top, left, right). No script is needed. The bottom edge is intentionally absent — the ball exits through it.

**Project context**:
- Working directory: `/Users/mustafa_elhelbawy/Documents/Work/deep-break-game`
- Godot 4.3 GDScript project. Viewport is 360×780 portrait.
- `WorldBoundaryShape2D` is used instead of `RectangleShape2D` because infinite planes never need resizing when the viewport changes on different Android screen sizes.
- No autoload references in this scene — it is pure physics geometry.

**Step 1 — Write `scenes/game/Walls.tscn`**

Create the file with this exact content:

```
[gd_scene load_steps=4 format=3]

[sub_resource type="WorldBoundaryShape2D" id="top"]
normal = Vector2(0, 1)

[sub_resource type="WorldBoundaryShape2D" id="left"]
normal = Vector2(1, 0)

[sub_resource type="WorldBoundaryShape2D" id="right"]
normal = Vector2(-1, 0)

[node name="Walls" type="Node2D"]

[node name="WallTop" type="StaticBody2D" parent="."]
position = Vector2(180, 0)

[node name="CollisionShape2D" type="CollisionShape2D" parent="WallTop"]
shape = SubResource("top")

[node name="WallLeft" type="StaticBody2D" parent="."]
position = Vector2(0, 390)

[node name="CollisionShape2D" type="CollisionShape2D" parent="WallLeft"]
shape = SubResource("left")

[node name="WallRight" type="StaticBody2D" parent="."]
position = Vector2(360, 390)

[node name="CollisionShape2D" type="CollisionShape2D" parent="WallRight"]
shape = SubResource("right")
```

> **Normal direction explanation**:
> - `WallTop` normal `(0, 1)`: the plane faces downward (+Y in Godot 2D = downward). A ball hitting the top wall gets pushed down and back into the play area.
> - `WallLeft` normal `(1, 0)`: faces right — reflects balls moving left.
> - `WallRight` normal `(-1, 0)`: faces left — reflects balls moving right.
>
> Positions place each wall at the corresponding viewport edge. `WorldBoundaryShape2D` is an infinite plane so the position only determines which side of the viewport it covers — the plane extends infinitely in both directions along its tangent.
