### Step 3 — Wire brick_hit in Brick.gd

Open `scenes/game/Brick.gd`. Find the `take_hit()` method. The brick plays the DESTROY sound when HP reaches 0 — this call may already exist (added in T036). Add the HIT sound when HP decrements but does NOT reach 0:

Locate the HP decrement logic. It will look roughly like:
```gdscript
func take_hit() -> void:
    if _hit_points == 0:   # indestructible
        return
    _hit_points -= 1
    if _hit_points <= 0:
        # destroy path
        ...
    else:
        # brick survived — add hit sound here
```

**Add in the `else` branch** (brick survived the hit):
```gdscript
    else:
        # [JS equiv]  audioManager.play('brickHit')
        AudioManager.play("brick_hit")
        # Optional visual feedback: brief flash white, fade back to tier colour.
        # (Phase 4 may already have a modulate tween here — add after it if so.)
```
