## Part A — AI Agent Prompt

**Task**: (1) Teach `Brick.gd` to store its `powerup_type` and emit a signal on destroy. (2) Relay that signal through `BrickGrid.gd`. (3) Wire `Game.gd` to spawn `PowerUp.tscn` from the relayed signal and connect the `caught` signal to `_on_powerup_caught(type)` (stub — effects are implemented in T053–T055).

> **Architecture amendment (ADR-002)**: The original approach had `Brick.gd` preloading `PowerUp.tscn` and calling `get_tree().current_scene.add_child(token)` directly. This couples Brick to PowerUp visuals and uses a fragile scene-tree reference. The correct approach follows the existing signal relay pattern: Brick emits `powerup_dropped(type, pos)` → BrickGrid relays → Game.gd spawns the token.

### Step 1 — Brick.gd: store powerup_type and emit signal on destroy

Open `scenes/game/Brick.gd`.

**Add signal** near the top with other signals:
```gdscript
## Emitted on destroy if this brick carries a power-up.
## BrickGrid relays this to Game.gd, which spawns the visual token.
## [JS equiv]  this.emit('powerupDropped', type, position)
signal powerup_dropped(type: String, pos: Vector2)
```

**Add state variable** in the state section:
```gdscript
# Power-up type this brick will drop on destroy. "" = none.
# Set by BrickGrid.gd via set_powerup_type() after spawning.
# [JS equiv]  #powerupType = ''  (private class field)
var _powerup_type: String = ""
```

**Add setter method** (called by BrickGrid during spawn):
```gdscript
## Assign a power-up type to this brick. Called by BrickGrid after instantiation.
func set_powerup_type(type: String) -> void:
	_powerup_type = type
```

**In the destroy path of `take_hit()`** (when `_hit_points <= 0`), add the emit BEFORE `queue_free()`:
```gdscript
		# Signal a power-up drop if assigned. BrickGrid relays this to Game.gd.
		# [JS equiv]  if (this._powerupType) this.emit('powerupDropped', this._powerupType, this.pos)
		if _powerup_type != "":
			emit_signal("powerup_dropped", _powerup_type, global_position)
		# ... existing destroy logic (emit destroyed signal, queue_free, etc.) ...
```

**Do NOT add a `PowerUpScene` preload to Brick.gd.** Brick is a data node — it does not own visual token spawning.

### Step 2 — BrickGrid.gd: relay powerup_dropped signal

Open `scenes/game/BrickGrid.gd`.

**Add relay signal** near the top with other signals:
```gdscript
## Relayed from Brick.powerup_dropped — received by Game.gd to spawn the token.
signal powerup_dropped(type: String, pos: Vector2)
```

**In the `spawn()` loop**, after connecting the other brick signals (destroyed, hit), add:
```gdscript
		# Relay power-up drop signal upward to Game.gd.
		# [JS equiv]  brick.on('powerupDropped', (...args) => this.emit('powerupDropped', ...args))
		brick.powerup_dropped.connect(_on_powerup_dropped)
```

**Add the relay handler**:
```gdscript
func _on_powerup_dropped(type: String, pos: Vector2) -> void:
	# Pass through to Game.gd — BrickGrid does not own token spawning.
	emit_signal("powerup_dropped", type, pos)
```

Also in the `spawn()` loop, call `set_powerup_type()` when the descriptor has a type:
```gdscript
		# Apply power-up type from descriptor (empty string = no power-up).
		if desc.get("powerup_type", "") != "":
			brick.set_powerup_type(desc["powerup_type"])
```

### Step 3 — Game.gd: preload PowerUp, connect relay, spawn token

Open `scenes/game/Game.gd`.

**Add preload** near the top (with other const preloads):
```gdscript
# Power-up token scene — spawned here (not in Brick.gd) to keep visuals out of data nodes.
# [JS equiv]  import PowerUpScene from './PowerUp.js'
const PowerUpScene: PackedScene = preload("res://scenes/game/PowerUp.tscn")
```

**In `_ready()`, after connecting `_grid.brick_destroyed`, add**:
```gdscript
# Wire power-up relay from BrickGrid.
# [JS equiv]  this._grid.addEventListener('powerupDropped', this._onPowerupDropped.bind(this))
_grid.powerup_dropped.connect(_on_powerup_dropped)
```

**Add the spawn handler**:
```gdscript
## Called when a brick with a power-up is destroyed.
## Spawns the falling token at the brick's world position.
func _on_powerup_dropped(type: String, pos: Vector2) -> void:
	var token: Area2D = PowerUpScene.instantiate()
	add_child(token)
	# Position at brick's world position — token then falls under its own logic.
	# [JS equiv]  token.position = pos; token.setup(type)
	token.global_position = pos
	token.setup(type)
	# Connect catch signal — routes to the power-up activation handler (T053–T055).
	token.caught.connect(_on_powerup_caught)
```
