**Task**: Execute T016 from the Deep Break project — add the Android export preset to `export_presets.cfg`, export a debug APK via the Godot CLI, and install it on a connected Android device.

**Project context**:
- Working directory: the cloned Deep Break repo on the build machine
- Godot 4.3 stable CLI must be in PATH (`godot --version` returns `4.3.stable`)
- Android SDK installed, `adb` in PATH (T015 complete)
- This is a **debug** export for Phase 1 testing — no signing keys needed yet
- `export_presets.cfg` must be created and committed back to the repo (it is not gitignored)
- The `build/` directory IS gitignored — APK output goes there but is never committed

**Step 1 — Check whether `export_presets.cfg` already exists**

Read `export_presets.cfg` in the project root.

- If it exists and contains an `[preset.0]` section for Android: skip to Step 3.
- If it does not exist or is empty: proceed to Step 2.

**Step 2 — Create `export_presets.cfg`**

Create the file at the project root with this content:

```ini
[preset.0]

name="Android Debug"
platform="Android"
runnable=true
export_filter="all_resources"
include_filter=""
exclude_filter=""
export_path="build/android/DeepBreak-debug.apk"
encrypt_pck=false
encrypt_directory=false

[preset.0.options]

custom_template/debug=""
custom_template/release=""
gradle_build/use_gradle_build=true
gradle_build/export_format=0
gradle_build/min_sdk=26
gradle_build/target_sdk=33
gradle_build/compress_native_libraries=true
gradle_build/ignore_libs=[]
package/unique_name="com.deepbreak.game"
package/name="Deep Break"
package/signed=false
package/classify_as_game=true
launcher_icons/main_192x192=""
launcher_icons/adaptive_foreground_432x432=""
launcher_icons/adaptive_background_432x432=""
graphics/opengl_debug=false
xr_features/xr_mode=0
screen/immersive_mode=true
screen/orientations=1
screen/support_small=true
screen/support_normal=true
screen/support_large=true
screen/support_xlarge=true
user_data_backup/allow=false
command_line/extra_args=""
apk_expansion/enable=false
permissions/access_network_state=false
permissions/internet=false
```

> **Key settings**:
> - `screen/orientations=1` → portrait only (matches constitution)
> - `gradle_build/min_sdk=26` → Android 8.0 minimum (spec requirement)
> - `package/signed=false` → debug export, no keystore needed
> - `gradle_build/use_gradle_build=true` → required for Godot 4 Android export

**Step 3 — Create the build output directory**

```bash
mkdir -p build/android
```

**Step 4 — Export the debug APK**

```bash
# Mac / Linux
godot --headless --export-debug "Android Debug" build/android/DeepBreak-debug.apk

# Windows PowerShell
godot.exe --headless --export-debug "Android Debug" build\android\DeepBreak-debug.apk
```

This command:
- Runs Godot without a display (`--headless`)
- Exports using the preset named `"Android Debug"` from `export_presets.cfg`
- Outputs the APK to `build/android/DeepBreak-debug.apk`

Expected output (approximately):
```
Godot Engine v4.3.stable - https://godotengine.org
...
Converting project...
Exporting project...
Export successful.
```

**If export fails**, check common errors:
```
"No export template found":
  → Run T015 Step B5 — export templates not installed

"Android SDK not found":
  → Run T015 Step B4 — SDK path not set in Godot editor settings

"Gradle build failed":
  → Check JAVA_HOME points to JDK 17 (not JDK 8 or 11)
  → Check internet access — first Gradle build downloads dependencies (~100 MB)

"export_presets.cfg: preset 'Android Debug' not found":
  → Confirm the preset name in export_presets.cfg matches exactly (case-sensitive)
```

**Step 5 — Verify the APK was created**

```bash
ls -lh build/android/DeepBreak-debug.apk
# Expected: file exists, size between 30–80 MB
```

**Step 6 — Install on a connected Android device**

Enable USB debugging on the Android device:
- Settings → About Phone → tap "Build Number" 7 times → Developer Options appear
- Settings → Developer Options → USB Debugging → ON

Connect via USB cable, then:
```bash
adb devices
# Must list your device (not "unauthorized" — accept the prompt on the device if needed)

adb install build/android/DeepBreak-debug.apk
# Expected: "Success"
```

If no device is connected and you want to use an emulator:
```bash
# List available emulators (must have created one via Android Studio AVD Manager)
emulator -list-avds

# Start an emulator (replace 'Pixel_5_API_33' with your AVD name)
emulator -avd Pixel_5_API_33 &

# Wait ~30 seconds, then:
adb install build/android/DeepBreak-debug.apk
```

**Step 7 — Commit `export_presets.cfg`**

Stage and commit only `export_presets.cfg` (APKs are gitignored):

```
feat: T016 — Android export preset (debug, API 26+, portrait)
```

Push to the repo so the Mac developer has the preset.
