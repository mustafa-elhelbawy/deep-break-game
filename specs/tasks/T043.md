### Part 1 — On-device smoke test (BUILD machine)

Run through each item. Mark pass (✓) or fail (✗). For any failure, note the step and error.

#### App launch

- [ ] App appears in app drawer as "Deep Break"
- [ ] Tapping the icon launches the game in under 3 seconds
- [ ] No crash or ANR within the first 30 seconds
- [ ] Background is dark navy — not grey, not black
- [ ] No Godot "!" error icon in the corner

#### Visual — Phase 4 effects on device

- [ ] Tier 0 bricks render **teal** (`#00c8b8`)
- [ ] Tier 1 bricks render **cyan** (`#00e0ff`)
- [ ] Tier 2 bricks render **amber** (`#ffc107`)
- [ ] Tier 3 / indestructible bricks render **violet** (`#b167ff`)
- [ ] Paddle renders **teal**
- [ ] Ball renders **soft white** (not pure white)
- [ ] Subtle glow halo visible around bricks/ball (bloom active)

#### Core gameplay — Phase 1–3

- [ ] Tap anywhere → ball launches from paddle
- [ ] Ball reflects off left wall, right wall, and top wall
- [ ] Ball reflects off paddle
- [ ] Paddle follows finger drag in the lower zone
- [ ] Brick takes hit → HP decrements (tier 1 = 1 hit, tier 2 = 2 hits, tier 3 = 3 hits)
- [ ] Tier 0 brick destroyed in 1 hit; vanishes
- [ ] Indestructible brick (tier 3 if present) never vanishes
- [ ] Score increments: tier 0 = 10 pts, tier 1 = 20 pts, tier 2 = 30 pts
- [ ] HUD score updates in real time
- [ ] Lives = 3 at start (shown in HUD)
- [ ] Ball exits bottom → life lost → ball resets to paddle → bricks unchanged
- [ ] HUD lives counter decrements correctly
- [ ] At 0 lives → Game Over screen appears with final score
- [ ] "Restart" button on Game Over → new game starts (lives = 3, score = 0)

#### Juice effects — Phase 4

- [ ] Brick destroy → particle burst appears at brick position
- [ ] Burst tinted with tier colour (teal/cyan/amber/violet)
- [ ] Burst particle nodes disappear after ~0.5 s (no memory leak)
- [ ] Screen shakes briefly on each brick destroy
- [ ] Paddle hit near left edge → ball deflects left
- [ ] Paddle hit near right edge → ball deflects right
- [ ] Paddle centre hit → ball travels mostly vertical

#### Level progression

- [ ] All non-indestructible bricks destroyed → Level Clear screen appears
- [ ] "Next Level" button → level 2 starts, new brick layout generated
- [ ] Level 2 layout visibly different from level 1
- [ ] Ball speed noticeably faster at level 5 vs level 1
- [ ] Same seed + same level produces the same layout on repeat runs

#### Performance (visual check — no profiler needed on device)

- [ ] Frame rate feels smooth (no visible stuttering during particle bursts)
- [ ] No frame drops during brick destroy events
- [ ] Glow effect does not cause obvious slowdown
