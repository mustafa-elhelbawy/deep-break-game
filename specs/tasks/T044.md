### Step 2 — Create `Logo.tscn`

**Scene tree**:
```
Logo (Node2D)           ← root; will be instanced by Title.tscn
├── DeepLabel  (Label)  ← "DEEP"
├── BreakLabel (Label)  ← "BREAK"
└── AnimationPlayer     ← floating sine animation
```

**DeepLabel settings** (Inspector):
- Text: `DEEP`
- Horizontal Alignment: Center
- Vertical Alignment: Center
- Position: `(0, -44)` (above centre)

**DeepLabel → LabelSettings** (create new `LabelSettings` resource inline):
```
Font: assets/fonts/Orbitron-Bold.ttf
Font Size: 64
Font Color: #00c8b8         ← teal
Outline Size: 4
Outline Color: #004d47      ← dark teal
```

**BreakLabel settings**:
- Text: `BREAK`
- Horizontal Alignment: Center
- Vertical Alignment: Center
- Position: `(0, 44)`

**BreakLabel → LabelSettings**:
```
Font: assets/fonts/Orbitron-Bold.ttf
Font Size: 64
Font Color: #ffc107         ← amber
Outline Size: 4
Outline Color: #7a5c00      ← dark amber
```

**Logo (Node2D) position**: `(180, 300)` — centred horizontally, upper third of the 360×780 viewport.

---

### Step 3 — Floating animation

Select `AnimationPlayer`. Create a new animation named `"float"`:
- Duration: `3.0` s, loop enabled.
- Track: `Logo:position:y`
  - Key at t=0.0: `300`
  - Key at t=1.5: `308`  (8px lower)
  - Key at t=3.0: `300`  (back up)
  - Easing: sinusoidal (set both keys to "ease in/out")

Auto-play: set `AnimationPlayer.autoplay = "float"` in the Inspector.
