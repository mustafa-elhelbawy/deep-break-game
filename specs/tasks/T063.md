### Step 2 — Add set_flipped() method

```gdscript
## Switch the active touch zone. Call from Game.gd in _apply_flip().
## v: true = upper 40% (flipped level), false = lower 40% (normal level).
func set_flipped(v: bool) -> void:
	_flipped = v
	# Release any currently held touch — prevents the paddle from locking to a drag
	# that started in the OLD zone before the flip was applied.
	# [JS equiv]  this._activeTouchId = null
	_active_touch_index = -1
```

### Step 3 — Update _handle_touch() zone check

Find `_handle_touch()`. The zone threshold check currently looks like:
```gdscript
var lower_zone_top: float = _screen_height * 0.60
if event.pressed:
    if _active_touch_index == -1 and event.position.y >= lower_zone_top:
```

**Replace with**:
```gdscript
func _handle_touch(event: InputEventScreenTouch) -> void:
	# Zone threshold depends on flip state.
	# Normal: lower 40% = y >= 60% of screen height.
	# Flipped: upper 40% = y <= 40% of screen height.
	# [JS equiv]  const inZone = flipped ? event.y <= threshold : event.y >= threshold
	if event.pressed:
		var in_zone: bool
		if _flipped:
			in_zone = event.position.y <= _screen_height * 0.40
		else:
			in_zone = event.position.y >= _screen_height * 0.60

		if _active_touch_index == -1 and in_zone:
			_active_touch_index = event.index
			_move_to_x(event.position.x)
	else:
		if event.index == _active_touch_index:
			_active_touch_index = -1
```

The `_handle_drag()` method requires no changes — it already ignores drags from unclaimed fingers, so only drags from within the correct zone (where the touch started) will move the paddle.
