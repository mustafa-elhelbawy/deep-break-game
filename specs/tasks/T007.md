**Task**: Execute T007 from the Deep Break project — create `scenes/game/Ball.tscn`. The scene contains a `CharacterBody2D` root (the ball physics body), a `CircleShape2D` collider, and a `Sprite2D` that shows the ball region from the atlas. No script is attached yet (T008 does that).

**Project context**:
- Working directory: `/Users/mustafa_elhelbawy/Documents/Work/deep-break-game`
- Godot 4.3 GDScript. Viewport 360×780. Atlas exists at `res://assets/textures/atlas.png`.
- Ball sprite region in the atlas: `Rect2(0, 0, 20, 20)` — soft white circle on dark background.
- `CharacterBody2D` with `motion_mode = 1` (Floating) is used. Floating mode disables Godot's built-in ground-snapping and gravity — the ball manages its own velocity entirely.
- `Ball.gd` (T008) will be the script. The `.tscn` references the script path so Godot will auto-attach it when T008 creates the file.

**Step 1 — Write `scenes/game/Ball.tscn`**

```
[gd_scene load_steps=4 format=3]

[ext_resource type="Script" path="res://scenes/game/Ball.gd" id="script"]
[ext_resource type="Texture2D" path="res://assets/textures/atlas.png" id="atlas"]

[sub_resource type="CircleShape2D" id="ball_shape"]
radius = 10.0

[node name="Ball" type="CharacterBody2D"]
motion_mode = 1
collision_layer = 1
collision_mask = 1
script = ExtResource("script")

[node name="CollisionShape2D" type="CollisionShape2D" parent="."]
shape = SubResource("ball_shape")

[node name="Sprite2D" type="Sprite2D" parent="."]
texture = ExtResource("atlas")
region_enabled = true
region_rect = Rect2(0, 0, 20, 20)
```

> **Node design notes**:
> - `motion_mode = 1` → `MOTION_MODE_FLOATING`. Value `0` would be `MOTION_MODE_GROUNDED` (adds gravity/floor snapping — wrong for a ball). This is one of the most common Godot breakout mistakes.
> - `collision_layer = 1`, `collision_mask = 1`: the ball lives on layer 1 and collides with anything else on layer 1 (walls, paddle, bricks — all on layer 1 by default).
> - The script path is set here. Godot will show a yellow warning icon until T008 creates `Ball.gd` — that is expected and will resolve automatically.
> - `region_rect = Rect2(0, 0, 20, 20)` pins this sprite to the ball tile in the atlas. Swapping the atlas PNG in Phase 4 requires no scene change.
