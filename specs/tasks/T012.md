**Project context**:
- Working directory: `/Users/mustafa_elhelbawy/Documents/Work/deep-break-game`
- Godot 4.3 GDScript. Viewport 360×780 portrait.
- All child scenes (Walls, Ball, Paddle) already exist.
- `Game.gd` (T013) will be the script — scene references the path.
- `Camera2D` uses `anchor_mode = 0` (Fixed Top Left) — do not use Drag Center; we want a locked viewport for mobile.
- Background is a `ColorRect` at full viewport size using `Palette.BACKGROUND` (`#0a0e1a`). This will be replaced by a `WorldEnvironment` in Phase 4.
- `BallSpawnPoint` is a `Marker2D` — a reference position only, no physics.
- Node order in the scene tree controls draw order (earlier = drawn first = behind). Background must be the first child.

**Step 1 — Write `scenes/game/Game.tscn`**

```
[gd_scene load_steps=5 format=3]

[ext_resource type="Script" path="res://scenes/game/Game.gd" id="script"]
[ext_resource type="PackedScene" path="res://scenes/game/Walls.tscn" id="walls"]
[ext_resource type="PackedScene" path="res://scenes/game/Ball.tscn" id="ball"]
[ext_resource type="PackedScene" path="res://scenes/game/Paddle.tscn" id="paddle"]

[node name="Game" type="Node2D"]
script = ExtResource("script")

[node name="Background" type="ColorRect" parent="."]
mouse_filter = 2
position = Vector2(0, 0)
size = Vector2(360, 780)
color = Color(0.039, 0.055, 0.102, 1)

[node name="Walls" parent="." instance=ExtResource("walls")]

[node name="BallSpawnPoint" type="Marker2D" parent="."]
position = Vector2(180, 660)

[node name="Paddle" parent="." instance=ExtResource("paddle")]
position = Vector2(180, 710)

[node name="Ball" parent="." instance=ExtResource("ball")]
position = Vector2(180, 680)

[node name="Camera2D" type="Camera2D" parent="."]
position = Vector2(180, 390)
anchor_mode = 0
position_smoothing_enabled = false
```

> **Node placement notes**:
> - `Background` first child → drawn behind everything else (Godot 2D draw order = tree order).
> - `mouse_filter = 2` on Background → `MOUSE_FILTER_IGNORE`. Prevents the ColorRect from consuming touch events before they reach the paddle.
> - `Paddle` at y=710, `Ball` at y=680: ball starts 30px above paddle (matching `reset_to_paddle` offset in Ball.gd).
> - `Camera2D anchor_mode = 0` → `ANCHOR_MODE_FIXED_TOP_LEFT`. The camera is stationary; `(180, 390)` centres it in the viewport. `position_smoothing_enabled = false` → no lag on the camera (critical for screen-shake in Phase 4 which drives the camera directly).
> - `BallSpawnPoint` is unused in Phase 1 but establishes the reference position for Phase 2 when the ball resets between lives.
