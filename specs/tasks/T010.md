**Task**: Execute T010 from the Deep Break project — create `scenes/game/Paddle.tscn`. The scene contains an `AnimatableBody2D` root, a `RectangleShape2D` collider, and a `Sprite2D` using the paddle region of the atlas.

**Project context**:
- Working directory: `/Users/mustafa_elhelbawy/Documents/Work/deep-break-game`
- Godot 4.3 GDScript. Viewport 360×780. Atlas at `res://assets/textures/atlas.png`.
- Paddle sprite region in atlas: `Rect2(0, 20, 120, 16)` — cyan rectangle.
- `AnimatableBody2D` is used (not `StaticBody2D` or `CharacterBody2D`). It is the correct Godot 4 type for objects you move by script: it notifies the physics engine of the motion each frame so the ball receives proper collision normals when bouncing off a moving paddle.
- `sync_to_physics = true` ensures the paddle's position change is visible to the physics engine on the same frame — prevents a one-frame gap where the ball can clip through a fast-moving paddle.
- The paddle node is added to the `"paddle"` group so `Ball.gd` can detect it with `is_in_group("paddle")` for angle-based deflection in Phase 4.
- `Paddle.gd` (T011) will be the script. Scene references the path so Godot auto-attaches it once T011 creates the file.

**Step 1 — Write `scenes/game/Paddle.tscn`**

```
[gd_scene load_steps=4 format=3]

[ext_resource type="Script" path="res://scenes/game/Paddle.gd" id="script"]
[ext_resource type="Texture2D" path="res://assets/textures/atlas.png" id="atlas"]

[sub_resource type="RectangleShape2D" id="paddle_shape"]
size = Vector2(120, 16)

[node name="Paddle" type="AnimatableBody2D"]
sync_to_physics = true
collision_layer = 1
collision_mask = 1
groups = ["paddle"]
script = ExtResource("script")

[node name="CollisionShape2D" type="CollisionShape2D" parent="."]
shape = SubResource("paddle_shape")

[node name="Sprite2D" type="Sprite2D" parent="."]
texture = ExtResource("atlas")
region_enabled = true
region_rect = Rect2(0, 20, 120, 16)
```

> **Node design notes**:
> - `AnimatableBody2D` vs `StaticBody2D`: a `StaticBody2D` moved by setting `position` directly each frame does not inform the physics engine of its velocity. The ball would bounce off it as if it were stationary — producing incorrect normals when the paddle is moving fast. `AnimatableBody2D` with `sync_to_physics = true` solves this.
> - `groups = ["paddle"]`: sets the node's group in the .tscn file. `Ball.gd` uses `is_in_group("paddle")` in Phase 4 for angle-based deflection overriding the default bounce normal.
> - `region_rect = Rect2(0, 20, 120, 16)`: pins the paddle sprite to the correct atlas region. Full 120px width matches the `RectangleShape2D` width.
