## Part A — AI Agent Prompt

**Task**: Create `scenes/game/Brick.tscn` — a single brick physics body. The scene uses a `StaticBody2D` root with a `RectangleShape2D` collider and a `Sprite2D` using the atlas. The script path is pre-set so Godot auto-attaches it when T019 creates `Brick.gd`.

**Project context**:
- Working directory: `/Users/mustafa_elhelbawy/Documents/Work/deep-break-game`
- Godot 4.3 GDScript. Viewport 360×780. Atlas at `res://assets/textures/atlas.png`.
- Brick sprite region: `Rect2(0, 36, 44, 18)` (tier 0 / teal) — runtime code swaps the region per tier.
- Node must be added to the `"bricks"` group so `Ball.gd` can call `collider.take_hit()` on it.
- Collision layer/mask = 1 (same layer as ball and walls).

**Step 1 — Write `scenes/game/Brick.tscn`**

```
[gd_scene load_steps=4 format=3]

[ext_resource type="Script" path="res://scenes/game/Brick.gd" id="script"]
[ext_resource type="Texture2D" path="res://assets/textures/atlas.png" id="atlas"]

[sub_resource type="RectangleShape2D" id="brick_shape"]
size = Vector2(44, 18)

[node name="Brick" type="StaticBody2D"]
collision_layer = 1
collision_mask = 1
groups = ["bricks"]
script = ExtResource("script")

[node name="CollisionShape2D" type="CollisionShape2D" parent="."]
shape = SubResource("brick_shape")

[node name="Sprite2D" type="Sprite2D" parent="."]
texture = ExtResource("atlas")
region_enabled = true
region_rect = Rect2(0, 36, 44, 18)
```
