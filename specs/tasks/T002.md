**Step 2 — Apply required settings to `project.godot`**

Read the current contents of `project.godot`. Then ensure the following keys exist with the exact values shown. If a section already exists, merge — do not delete existing keys. If a section is missing, append it.

Settings to apply:

```ini
[display]

window/size/viewport_width=360
window/size/viewport_height=780
window/stretch/mode="canvas_items"
window/stretch/aspect="keep"

[input_devices]

pointing/emulate_touch_from_mouse=true

[rendering]

renderer/rendering_method="mobile"
renderer/rendering_method.mobile="mobile"
```

> **Why these values**:
> - `360×780`: baseline portrait resolution — Godot scales to fit any Android screen via `canvas_items` stretch.
> - `canvas_items` + `keep`: scales the entire scene uniformly; adds letterbox on wider screens.
> - `emulate_touch_from_mouse`: lets you test touch-based paddle drag with the mouse in the Mac editor. Has zero effect on the Android build.
> - `renderer/rendering_method="mobile"`: uses Godot's lightweight mobile renderer. `forward_plus` is too GPU-heavy for mid-range Android.
