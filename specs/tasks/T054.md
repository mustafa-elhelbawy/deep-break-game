### Step 1 — Ball.gd: add speed modifier

Open `scenes/game/Ball.gd`.

**Add constant**:
```gdscript
# Slow Motion speed multiplier — ball moves at this fraction of level speed.
const SLOW_SPEED_MODIFIER: float = 0.55
```

**Add state variable**:
```gdscript
# Multiplier applied on top of _current_speed. 1.0 = normal; 0.55 = slow motion.
# [JS equiv]  #speedModifier = 1.0  (private class field)
var _speed_modifier: float = 1.0
```

**Update `_physics_process` (and wherever `_current_speed` is applied)**:

In `_move_and_reflect()`, both places that set `_velocity` use `_current_speed`. They must use the effective speed:

Locate this pattern (appears in the paddle branch AND the rescale line at the bottom):
```gdscript
_velocity = ... * _current_speed
```

For the rescale at the bottom of `_move_and_reflect()`:
```gdscript
	# Re-normalise to exact current speed, accounting for any active speed modifier.
	# [JS equiv]  this._velocity = this._velocity.normalize().multiplyScalar(this._currentSpeed * this._speedModifier)
	_velocity = _velocity.normalized() * (_current_speed * _speed_modifier)
```

For the paddle deflection block (Vector2(sin, cos) * speed):
```gdscript
	_velocity = Vector2(sin(angle), -abs(cos(angle))) * (_current_speed * _speed_modifier)
```

Also update `launch()`:
```gdscript
func launch(direction: Vector2) -> void:
	_velocity = direction.normalized() * (_current_speed * _speed_modifier)
	_active = true
	_stuck_timer = 0.0
```

**Add activate/revert methods**:
```gdscript
## Activate slow-motion. Immediately rescales current velocity.
## Safe to call while already active — resets internal modifier (timer managed by Game.gd).
func activate_slow() -> void:
	_speed_modifier = SLOW_SPEED_MODIFIER
	# Rescale existing velocity immediately — no need to wait for next bounce.
	# [JS equiv]  this._velocity = this._velocity.normalize().multiplyScalar(effectiveSpeed)
	if _active:
		_velocity = _velocity.normalized() * (_current_speed * _speed_modifier)

## Revert slow-motion modifier to normal. Called by Game.gd when timer expires.
func revert_slow() -> void:
	_speed_modifier = 1.0
	if _active:
		_velocity = _velocity.normalized() * _current_speed
```

### Step 2 — Game.gd: route S in _on_powerup_caught

Open `scenes/game/Game.gd`.


**Update `_on_powerup_caught()`**:
```gdscript
func _on_powerup_caught(type: String) -> void:
	match type:
		"W":
			_paddle.activate_wide()
		"S":
			_activate_slow()
		"M":
			pass  # T055
```

**Add `_activate_slow()` and `_revert_slow()`**:
```gdscript
func _activate_slow() -> void:
	# Cancel existing timer if S was already active.
	if _slow_timer != null and is_instance_valid(_slow_timer):
		if _slow_timer.timeout.is_connected(_revert_slow):
			_slow_timer.timeout.disconnect(_revert_slow)

	# Apply to primary ball.
	_ball.activate_slow()

	# Apply to any extra balls (multi-ball case from T055).
	# _extra_balls is added in T055 — safe to skip if not present yet.
	if has_method("_get_extra_balls"):
		for b in _get_extra_balls():
			b.activate_slow()

	_slow_timer = get_tree().create_timer(SLOW_DURATION)
	_slow_timer.timeout.connect(_revert_slow)
	# TODO T056: _hud.show_powerup("S", SLOW_DURATION)

func _revert_slow() -> void:
	_ball.revert_slow()
	if has_method("_get_extra_balls"):
		for b in _get_extra_balls():
			b.revert_slow()
	_slow_timer = null
```
