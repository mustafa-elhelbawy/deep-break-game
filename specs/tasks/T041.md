## Part A — AI Agent Prompt

**Task**: Verify the Windows build machine has all prerequisites installed, then generate the release keystore if it doesn't already exist. This is a one-time setup task.

**Project context**:
- Build machine is Windows (PowerShell). Git, JDK 17, and Android SDK may already be partially installed from earlier phases.
- Godot CLI must be on PATH. Export templates for 4.3.stable must be installed.
- Keystore must be generated and stored outside the repo.

---

### Step 1 — Verify Godot CLI

```powershell
godot.exe --version
```

Expected output contains `4.3.stable`. If not found:
1. Download `Godot_v4.3-stable_win64.exe` from https://godotengine.org/download
2. Rename to `godot.exe`, place in `C:\tools\godot\`
3. Add `C:\tools\godot` to system PATH (System Properties → Advanced → Environment Variables)

---

### Step 2 — Install Android export templates

Check if templates exist:

```powershell
Test-Path "$env:APPDATA\Godot\export_templates\4.3.stable\android_release.apk"
```

If `False`:
```powershell
# Download Godot_v4.3-stable_export_templates.tpz from:
# https://github.com/godotengine/godot/releases/tag/4.3-stable
# Then install:
godot.exe --headless --install-export-templates Godot_v4.3-stable_export_templates.tpz
```

Verify again — should now return `True`.

---

### Step 3 — Verify JDK 17

```powershell
java -version     # must show openjdk 17
keytool -help     # must not fail
```

If missing: download Adoptium Temurin 17 from https://adoptium.net/ and install. Ensure `bin/` is on PATH.

---

### Step 4 — Verify Android SDK

```powershell
$env:ANDROID_HOME = "C:\Android"   # adjust to actual install location
sdkmanager --list_installed
```

Required packages:
- `platform-tools`
- `platforms;android-33`
- `build-tools;33.0.2`

Install any that are missing:
```powershell
sdkmanager "platform-tools" "platforms;android-33" "build-tools;33.0.2"
sdkmanager --licenses
```

---

### Step 5 — Point Godot at the Android SDK (one-time editor step)

This step requires opening the Godot editor once:
1. Open `project.godot` in the Godot editor on the Windows machine
2. Go to: Editor → Editor Settings → Export → Android
3. Set **Android SDK Path** to `C:\Android` (or wherever `$ANDROID_HOME` points)
4. Close the editor — all future builds are headless

> If the build machine has no display (pure CI server), skip this step and instead configure the SDK path via the Godot user data config file (`%APPDATA%\Godot\editor_settings-4.tres` — set `export/android/android_sdk_path`).

---

### Step 6 — Generate the release keystore (first time only)

If `deep-break.keystore` does not already exist in a secure location:

```powershell
# Choose a safe location OUTSIDE the repo (e.g., C:\keys\)
New-Item -ItemType Directory -Force -Path C:\keys

keytool -genkey -v `
  -keystore C:\keys\deep-break.keystore `
  -alias deep-break-key `
  -keyalg RSA `
  -keysize 2048 `
  -validity 10000
```

When prompted:
- Enter a strong password (record it in your password manager)
- Organisation fields: any values are acceptable for self-signing
- Key password: use the same password as the keystore for simplicity

**Record these three values securely** — you will need them for every build:

| Variable | Value |
|----------|-------|
| `DEEP_BREAK_KEYSTORE_PATH` | `C:\keys\deep-break.keystore` |
| `DEEP_BREAK_KEY_ALIAS` | `deep-break-key` |
| `DEEP_BREAK_KEY_PASSWORD` | *(the password you just set)* |
