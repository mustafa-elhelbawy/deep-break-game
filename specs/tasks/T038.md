### Step 2 — Manual smoke-test checklist

Run the game with **F5** in the Godot editor. Work through each item:

#### Visual

- [ ] Background is dark navy (#0a0e1a) — not grey
- [ ] Bricks render in tier colours: teal (tier 0) / cyan (tier 1) / amber (tier 2) / violet (tier 3)
- [ ] Paddle renders in teal
- [ ] Ball renders as soft white (#e0ecff)
- [ ] Subtle glow halo visible around bricks and ball
- [ ] Frame rate ≥ 55 fps (Debugger → Profiler in editor)

#### Juice effects

- [ ] Destroying a brick spawns a short particle burst at the brick's position
- [ ] Particle burst is tinted with the tier colour (teal/cyan/amber/violet)
- [ ] Camera shakes briefly on each brick destroy
- [ ] Particle nodes are removed after lifetime (no leak — check Scene tree panel)

#### Audio events

- [ ] Brick destroy → `brick_destroy` SFX fires (no crash; silent OGG is expected)
- [ ] Ball lost → `ball_lost` SFX fires (no crash)
- [ ] Game over → `game_over` SFX fires (no crash)
- [ ] Level clear → `level_clear` SFX fires (no crash)
- [ ] Paddle hit → deflection angle changes based on contact position (left/centre/right)

#### Regression (Phase 1–3 still working)

- [ ] Ball launches from paddle on tap/click
- [ ] Bricks take correct hits (tier 0 = 1 HP, tier 2 = 3 HP)
- [ ] Indestructible bricks (tier 3) never break
- [ ] Score increments correctly per tier: tier 0 = 10 pts, tier 2 = 30 pts
- [ ] Lives decrement on ball lost; game over at 0 lives
- [ ] Bricks persist across death within same level (no reset on life lost)
- [ ] Level clears when last non-indestructible brick is destroyed
- [ ] Level 5 increases ball speed vs level 1
