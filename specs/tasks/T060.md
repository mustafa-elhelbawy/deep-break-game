### Step 1 — LevelGenerator.gd: implement flip logic

Open `scripts/autoloads/LevelGenerator.gd`. Find the return statement at the bottom of `generate()`:

**Current**:
```gdscript
	return {
		"bricks":         result,
		"layout_flipped": false,
	}
```

**Replace with**:
```gdscript
	# ── Flip decision ─────────────────────────────────────────────────────────
	# layout_flipped: ~20% chance for levels 3+. Seeded — same level + seed = same flip.
	# Uses a SEPARATE rng draw AFTER all brick generation draws to preserve existing
	# seed reproducibility for the brick layout.
	# [JS equiv]  const flipped = level >= 3 && rng.random() < 0.20
	var layout_flipped: bool = false
	if level >= 3:
		layout_flipped = rng.randf() < 0.20

	return {
		"bricks":         result,
		"layout_flipped": layout_flipped,
	}
```

> **RNG order rule**: This `rng.randf()` call is placed AFTER all brick descriptor generation. It is the very last rng call. This ensures the flip decision does not shift any brick layout draws.

### Step 2 — Game.gd: store and apply the flipped flag

Open `scenes/game/Game.gd`.

**Add state variable**:
```gdscript
# True when the current level is in "flipped" mode (paddle at top, bricks at bottom).
# [JS equiv]  #flipped = false

```

**Update `_spawn_level()`**:
```gdscript
func _spawn_level() -> void:
	var level_data: Dictionary = LevelGenerator.generate(GameManager.seed, GameManager.level)

	# Apply flip mode BEFORE spawning bricks so BrickGrid uses the right orientation.
```

> **Note**: `_grid.spawn()` currently takes only `descriptors` — T061 will update `BrickGrid.spawn()` to accept the `flipped` parameter.
