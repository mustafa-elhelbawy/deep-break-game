### Step 1 — Walls.tscn: add WallBottom node

Open `scenes/game/Walls.tscn`. Add a 4th child:

```
WallBottom (StaticBody2D)
└── CollisionShape2D  [WorldBoundaryShape2D]
```

**WallBottom settings**:
- CollisionShape2D → WorldBoundaryShape2D → Normal: `(0, -1, 0)` (points upward into play area)
- Position: `(180, 780)` — at the bottom edge of the 360×780 viewport
- **Process Mode: Disabled** (disabled by default; enabled only in flipped levels)

To disable it by default: Select WallBottom → Inspector → Node → Process Mode → **Disabled**, AND also set `CollisionShape2D.disabled = true`.

> Using `disabled = true` on the shape (not the StaticBody2D) is the safest way — the body itself stays in the tree but its shape doesn't participate in collision.

### Step 2 — Ball.gd: add set_flipped(), park(), and update _check_lost()

Open `scenes/game/Ball.gd`.

**Add state variable**:

```gdscript
# When true, the ball is lost if it exits the TOP of the screen (flipped level).
# When false (default), lost if it exits the BOTTOM (normal level).
# [JS equiv]  #flipped = false
var _flipped: bool = false
```

**Add methods**:
```gdscript
## Switch the death-edge direction. Call from Game.gd before each new level.
func set_flipped(v: bool) -> void:
	_flipped = v

## Stop the ball and place it at the given world position.
## Used by Game.gd to park the ball on the paddle without accessing private fields.
## (ADR-004 — avoids Game.gd writing _active and _velocity directly)
## [JS equiv]  park(worldPos) { this._active = false; this._velocity = Vector2.ZERO; this.position = worldPos }
func park(world_pos: Vector2) -> void:
	_active = false
	_velocity = Vector2.ZERO
	global_position = world_pos
```

**Update `_check_lost()`**:
```gdscript
func _check_lost() -> void:
	var screen_h: float = get_viewport().get_visible_rect().size.y
	if _flipped:
		# Flipped mode: ball exits the TOP = lost (y < 0 - grace).
		# [JS equiv]  if (this.y < -20) this.emit('lost')
		if global_position.y < -20.0:
			_active = false
			emit_signal("lost")
	else:
		# Normal mode: ball exits the BOTTOM = lost.
		if global_position.y > screen_h + 20.0:
			_active = false
			emit_signal("lost")
```

### Step 3 — Game.gd: add _apply_flip()

Open `scenes/game/Game.gd`. Add node references for the wall nodes:

```gdscript

@onready var _wall_bottom: StaticBody2D = $Walls/WallBottom
```

**Add constant positions**:
```gdscript
const PADDLE_Y_NORMAL:  float = 710.0
const PADDLE_Y_FLIPPED: float = 70.0
const BALL_OFFSET_Y:    float = 30.0   # ball sits this many px from paddle
```

**Add `_apply_flip()` method**:
```gdscript
func _apply_flip(flipped: bool) -> void:
	_flipped = flipped

	if flipped:
		# Move paddle to top.
		# [JS equiv]  this._paddle.position.y = PADDLE_Y_FLIPPED
		_paddle.position.y = PADDLE_Y_FLIPPED

		# WallTop: disable collision (ball can now pass through top — it is the death edge).
		_wall_top.get_node("CollisionShape2D").set_deferred("disabled", true)

		# WallBottom: enable collision (ball bounces off bottom in flipped mode).
		_wall_bottom.get_node("CollisionShape2D").set_deferred("disabled", false)

		# Tell Ball.gd to check the top edge for lost detection.
		_ball.set_flipped(true)
	else:
		# Restore normal layout.
		_paddle.position.y = PADDLE_Y_NORMAL
		_wall_top.get_node("CollisionShape2D").set_deferred("disabled", false)
		_wall_bottom.get_node("CollisionShape2D").set_deferred("disabled", true)
		_ball.set_flipped(false)
```

**Update `_spawn_level()` to call `_apply_flip`**:
```gdscript
func _spawn_level() -> void:
```

**Update `reset_to_paddle` calls** — in flipped mode the ball sits BELOW the paddle (not above):

Call `_place_ball_on_paddle()` wherever `_ball.reset_to_paddle(...)` was previously called in Game.gd. Remove the old `reset_to_paddle` calls that pass `_paddle.global_position` directly — `_place_ball_on_paddle()` replaces them.

> This avoids accessing `_ball._active` and `_ball._velocity` from outside Ball.gd. The `park()` method on Ball.gd is the clean public API (ADR-004).

```gdscript
func _wire_mobile_bricks() -> void:
	# In flipped mode, paddle is at the top and bricks fall upward.
	# The paddle threshold is at the top (y ≈ 70) not the bottom.
	var paddle_y: float = _paddle.global_position.y

	for brick in _grid.get_mobile_bricks():
		brick.set_paddle_y(paddle_y)
		if _flipped:
			# Invert fall direction for flipped mode.
			# set_mobile_flipped is added here; alternatively negate _collapse_speed in Brick.gd.

			brick.reached_paddle.connect(_on_mobile_brick_hit)
```
